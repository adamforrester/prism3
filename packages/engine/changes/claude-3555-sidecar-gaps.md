The sidecar copies each typography, weight-role and gradient token's own `$description` from the tree, as the color tier
does, so type styles keep their face, line height, tracking, fluid range and link underline (#3555 G2). The floor note
names `surfaces.<mode>.floorStep` (and `surfaces.<mode>.inverseSecondary` on inverse entries) instead of a setting no
lever has. The layout tier names color roles by tree path (`color.border.focus`), and the sidecar note and schema list
background blur and the type line boxes in the layout tier.

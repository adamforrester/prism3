List and List item gain an `x-small` size (#3330), for tight rule lists such as password requirements. It sets the item text in body extra-small, 12/18, with a 16px bullet or number column, a 6px bullet, and a 16px check in a 24px icon column. The gap between items is 4px and follows density. Every type has the step, so each set grows from 9 to 12 members; an Update adds the 3 new members and leaves the existing 9 in place. No token is added or renamed.

Plugin: spec panels on the component page (#2830 phase 2; owner's answers Q2830.1 B, Q2830.2–.9 A). A new agent command, draw-specs, draws one spec panel per family in its own 880px column, 40px right of the family's usage panel and top-aligned with it. The panel holds anatomy numbered as the usage panel numbers it, then per-size redlines over a live specimen, each labeled with the variable and the px the file holds. Then come the color tables, then nesting and properties. Each color table has one row per binding, in fixed columns sized so every variable name in any set stays on one line, with a swatch and the hex the file resolves. A binding a state drops gets a row whose variable reads "none", with no swatch (Q2994.1, built on the recommendation A, pending the owner's answer). Update now reserves the spec column beside every family's usage panel, so every set moves once on the next Update. Build and Update never draw a spec panel. Update moves a live one with its set, and a usage panel redrawn further right pushes it right. A hand-edited spec panel is kept as "(edited)", below the fresh one in the spec column.

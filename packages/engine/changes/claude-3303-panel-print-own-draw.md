Plugin: Update no longer treats a usage panel Prism3 drew, and nobody touched, as a hand edit (#3303). The print recorded when a panel is drawn read every layer inside the panel's instances: the `_Doc-block` blocks, List.Item rows, Badge chips, markers. Those layers come from each instance's main component, and Update rebuilds those components, so an untouched panel printed differently afterwards. It was kept as "… (edited)" below a fresh panel (23 sets in the template after one Update). Now the print reads each instance only through what it overrides: the text, properties and visibility the draw wrote, plus anything a designer changed since. A text, fill or visibility edit inside a block still keeps the panel. Spec panels share the print and get the same reading. A panel printed before this change is compared in its own form: it is replaced while it still matches, and kept once a component it nests changes, as before. No emitted artifact, token or projected component surface moves, and the executor is unchanged.

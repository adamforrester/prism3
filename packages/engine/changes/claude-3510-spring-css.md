Each spring ships in the token CSS as a ready-to-use transition (#3510, owner Q-SP1 E): `motion.spring-easing.<name>`, the spring sampled into a CSS `linear()` curve, and `motion.spring-duration.<name>`, the time it takes to settle, for `snappy`, `gentle` and `bouncy`. Both come from the new `spring.ts`, which states the settle threshold (0.1% of the travel), the sampling density (at most every 5ms) and the error bound `test.ts` holds the curve to (0.005 of the travel); G5 (#3485) is to take Figma's paired spring duration from the same function. The durations are DTCG `duration` tokens and reach the conforming projection. The curves have the custom type `linearEasing`, because DTCG has no type for a `linear()` function, so the projection omits them and the engine writes them to a new per-brand `<brand>.css-only.json`, which only the shippable CSS build reads. The damping and stiffness stay in `motion.spring.*`, in the DTCG tree and Figma, and stay out of the CSS. `CONTRACT_VERSION` 15.2.0 → 15.3.0. The MCP `theme_brand` description now states the agent metadata as roughly 690,000 characters for a four-mode brand (was 590,000), the measured size once the springs' CSS leaves joined it.

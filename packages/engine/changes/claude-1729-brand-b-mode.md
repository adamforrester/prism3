The Prism3 reference theme gains **Brand B**, a custom mode (`brand-b`) that shows two brands in one file (#1729, owner decision Q-BB1 A). It is built on light, the mechanical default: Q-BB1 names no base. It swaps only Prism3's primary and accent colors, its display face and its gradient; neutrals, surfaces, status colors, radius, density, motion and shadows stay Prism3's. The identity is reused from the Aurora example brand: its primary and accent colors, its display face and, through the swap, its gradient. New input lever `modePalettes` (per-mode palette swap): in a named customizable mode, every role, the link, each interactive column and every gradient stop on a swapped palette draws from the replacement, anchored at the replacement's own shade and held to the same contrast floors. Primitives stay mode-invariant; the two replacement ramps (`brand-b-primary`, `brand-b-accent`) ship in every mode. A gradient a swap moves now carries a per-mode value. A per-mode font family's mode entry now carries its own description, so the overlay names the mode's face rather than light's. The plugin writes a mode-invariant `core` row (palette, dimension) to every mode `core` holds, so a per-mode face no longer leaves its other modes reading stale primitives.

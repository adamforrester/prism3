Plugin: Update file offers the usage panels a file is missing (#3137, owner decisions Q3137.1–8 A). While Documentation has panels on, the file read finds, with one search for panel tags, each family whose lead set is in the file and has no live usage panel. Update file lists them under Components as Usage panels, with one tick, "Draw {n} usage panels", on by default. Up to six names show inline; past six they sit under "Show the {n} sets". The panels ride the in-place update, scoped to those sets, so the page makes room and a version is saved first. The badge counts the group as one item, and its name adds ", usage panels". Documentation's Usage panels card gives the count and offers "Draw them with Update file". With panels off, its off line says how many panels stay, and Update file › Clean up offers "Remove {n} panels", which removes only the panels that still hold what was drawn. The agent gets the same removal as `panels-clean`. The executor is unchanged, and no emitted artifact, token or projected component surface moves.

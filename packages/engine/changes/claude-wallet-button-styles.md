WalletButton draws each wallet's own button per style (#3174). A new style axis carries each provider's styles in its SDK's own names (Apple Pay black, white and white-outline; Google Pay black and white; PayPal gold, blue, silver, white and black; Shop Pay purple), valid provider × style pairs only, with any first: the stand-in with the provider's logo and no fill, at the coordinate every member built before keeps. Each style shows the logo exactly as the provider's SDK draws it, on the ground and 1px edge the SDK paints, from a new button/ mark kind in the provider logo set (11 marks, captured from each provider's public SDK on 2026-10-30, each with its provenance record). The logo binds the button's height, so each provider's logo-to-height ratio holds at every size. The code prop buttonStyle becomes style, an enum of the same names, with any passing no style to the provider. WalletButton goes from 20 members to 74.

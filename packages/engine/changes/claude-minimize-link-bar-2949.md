The plugin can minimize to a link strip while the agent link stays on (#2949, owner decisions Q1 A, Q2 A, Q3 A and Q600 A). A Minimize tile beside the Agent tile, drawn only while the link is on, shrinks the window to a 440×40 strip: the link's dot, its status in the Activity drawer's words plus the running or last command and its age ("Agent listening · last: update-components 2m ago"), Restore and Turn off. Restore returns to the size from before, on the same page and state; Turn off switches the link off and restores the window. The strip skips the 380×420 floor and is never kept as the window size. Minimizing never changes the link or stops its poll. No token, emitted tree or projected component surface moves.

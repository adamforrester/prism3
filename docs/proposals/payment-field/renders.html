Parts
  1. legend — the group's name. Nests FieldLabel (a <fieldset>/<legend> in code). Text editable.
  2. number — nested TextField, inputmode="numeric", autocomplete="cc-number". Value stays LTR.
  3. cardMark — a swap slot at the number field's trailing edge, card-shaped (8:5), aria-hidden. Holds a neutral placeholder until the client nominates artwork.
  4. expiry — nested TextField, one input cc-exp, "MM / YY" shown in the label hint or placeholder.
  5. securityCode — nested TextField cc-csc; its trailing info glyph opens help in code (its own button).
  6. postalCode — nested TextField postal-code, behind a Figma-only toggle (on by default).
Each nested field keeps its own label, message, status and state.

States live on each nested field PLAN RENDER — NOT FIGMA

# What changed in 0.239.0

2026-11-21 · from 0.238.0 · 1 breaking change, 6 new, 24 fixes

These notes are generated from the engine's own records at 0.238.0 and at 0.239.0: the Figma component sets, the coded components and the token names. Every item is checked against those records.

- **Breaking:** a name is renamed, removed or retyped. Anything that uses the old name stops working until it uses the new one.
- **New:** a name is added. Nothing that already works changes.
- **Fix:** a value changes under a name that stays, such as a default or how a set is built.

Under **Figma**, a set is named as it appears in the file, and a property is a variant property in its panel. Under **Code**, a prop is a setting a developer passes to a coded component. Under **Tokens**, a token is a named value, such as a color or a size, that Figma variables and code both read; names are shown without the brand's root, such as `prism.`.

### claude-3871-weight-roles (minor)

A brand's weight roles must be whole numbers in [1, 1000] (#3871). A fractional weight such as 450.5 used to emit an alias that resolved nowhere, because a DTCG alias reads the `.` as a path separator, and a weight outside DTCG's fontWeight range of 1–1000 shipped a value the spec rejects. `brandTheme` now refuses both by role name, and the schema types each `typography.weightRoles` value as an integer in [1, 1000]. Per-mode weights (`modeLevers.<mode>.weights`) keep their [100, 900] range and must also be whole. Every committed brand's emission is unchanged.

### claude-3872-breakpoints-rise (minor)

A brand's breakpoints must rise (#3872). Each floor in `layout.breakpoints` must now be above the one before, as the schema's description already said. Out-of-order floors (`[0, 1024, 768]`) used to emit `lg` below `md`, a repeated floor named one width twice, and a negative floor sat below the first; each built cleanly. `brandTheme` now refuses them, naming the floor and the one it follows. A fractional floor is still allowed. Every committed brand's emission is unchanged.

### claude-3873-anchor-on-ramp (minor)

An authored interactive anchor must name a step on its column's ramp (#3873). `actionAnchorStep`, `destructiveAnchorStep`, `interactivePalettes[].anchorStep` and each `modeAnchors` step are now refused off the ramp, naming the nearest real step, as surface steps already are. Each is applied exactly, and an off-ramp step used to fall back to 500 without a word, so a typo shipped a step nobody chose, uncorrected, and the build blamed contrast. A `modeAnchors` column other than primary, destructive or a declared interactive column is refused instead of ignored. The resolver also refuses an exact anchor off the ramp rather than falling back. Every committed brand's emission is unchanged.

### claude-3874-shadow-tint-max (minor)

The global shadow tint amount must be in [0, 1] (#3874). The tint's lightness and chroma both scale with the amount, so `shadow.tint.amount: 50` used to compile cleanly into white shadows, invisible on a white page, and anything above 1 pushed the tint's chroma out of gamut. `brandTheme` now refuses an amount outside [0, 1] by name, as it already did for the per-mode tint, and the schema gains the same maximum. Every committed brand's emission is unchanged.

### claude-3875-brand-id-path (minor)

A brand id can no longer write outside the CLI's output directory (#3875, a security fix). The id names every file the CLI writes, and nothing checked it: `id: "../escaped"` wrote six files one level above `--out`, an id holding a slash crashed mid-write with a raw stack trace, and an empty id wrote hidden dotfiles. `brandTheme` now refuses an id that is empty or blank, holds a slash, backslash or NUL, or is `.` or `..`, and the schema refuses the same ids. `emitTheme` refuses to write any file outside its directory, checked before anything is written. The CLI reports a failed write as a readable error. An id that is a safe file name but not a slug still builds. Every committed brand's emission is unchanged.

### claude-3876-quote-round-trip (minor)

A brand name with a double quote survives a design.md round trip (#3876). The serializer wrote a quote inside a double-quoted string as `\"`, and the parser never decoded it, so every export and import added a backslash before each quote. The parser now decodes `\"` and `\\` in a double-quoted string, the serializer escapes a backslash as well as a quote (keys included), and the comment, key and flow scanners no longer end a string at an escaped quote. A double-quoted string that holds neither escape reads exactly as before. Every committed brand's emission is unchanged.

### claude-3984-design-md-round-trip (patch)

design.md keeps a line break and a quoted key's own spaces through an export and an import (#3984). The serializer wrote a line break inside a double-quoted value as it was, so the value's second line became a frontmatter line of its own and the export would not import; it now writes YAML's `\n` (and `\r`) escape, which the parser decodes, and never writes a value holding one bare. A quoted key was trimmed after it was decoded, so a key with a space at an end, or one that was a line break, came back without it; the raw text is trimmed instead. A new gate, `lint-design-md-round-trip.ts`, builds brand inputs from `theme-schema.json` that set every property, branch, enum value and boolean the schema allows, and fails by path on any that does not survive the round trip. No committed artifact changes.

### claude-3986-rtl-mirror (minor)

Right-to-left behavior is part of the component contract (#3986 parts 1 and 3, owner decision Q-RTL1 A). A part can now say what it does in right-to-left text with a `mirror` field: `reverses` (a box's row), `mirrors` (a glyph, or what a slot or nest holds, flips), `never` (it stays as drawn, or keeps left-to-right order) or `per-glyph` (an icon, by which glyph it is). Every def that describes right-to-left behavior now states it in the field too: 46 on their own parts, and the checkbox and radio groups through the rows they nest. The icon set lists which glyphs mirror (`RTL_MIRRORED_GLYPHS`: the left and right chevrons and arrows, the diagonal arrows and the external-link arrow). Each component's usage section, docs page and Figma usage panel shows a short "In RTL" note generated from the fields (DRAFT wording). RadioControl's and Spinner's right-to-left notes are reworded so they describe the component itself rather than the layout around it.

## (2026-10-15) — The built concept v4 and v5 mockups leave the tree (Q319.4)

Owner decision Q319.4 on #2583: the built `concept-v4.html` and `concept-v5.html` under `docs/superpowers/ui-redesign/` are deleted and gitignored; their `.src.html`, `build-v4.mjs`, `build-v5.mjs`, `audit-v5.mjs` and notes stay. Concept v6 is untouched, because the studio shell (`apps/studio/src/shell/pages.ts`, `state/verdict.ts`) cites it. Removed: 874,776 + 1,063,273 bytes = 1,938,049 bytes (about 1.9 MB) from the checkout.

- **The build scripts do not regenerate them at `main`, and that is not a regression.** Both builds run a coverage self-check whose oracle is `packages/engine/schema/lever-manifest.json`; the manifest has since gained `buttonTextHover`, which neither mockup homes, so `build-v4.mjs` and `build-v5.mjs` both exit 1 at this base, before and after this change. They do build at the commit that shipped each one (`46574c08` for v4, `fb79fe8b` for v5), checked in a detached worktree. So `concept-v4.md` and `concept-v5.md` now say "built by" the script, at that commit, and give the `git show` for the reviewed bytes.
- **A rebuild at the shipping commit is not byte-identical to what was committed** — it differs in the embedded engine version and `builtAt` (the committed files were built against an engine one or two minors older than their own merge commit). The 2026-10 entry warning not to compare a rebuilt mockup with the committed one already said this; the `git show` line is the one route to the reviewed bytes.
- No gate, test or link read either file: the only references were the two notes, `v4-spec.md`, the build and audit scripts' own comments, and folded log entries (left as history).

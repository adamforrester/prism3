## (2026-10-18) — A refused property is a miss, a refused structure stops the set (#982)

Owner decision on #982 (triage Q319.2, a technical call delegated to engineering): a refused PROPERTY write is a miss and the member keeps building; a refused STRUCTURE call stops the member or set. The rule is recorded above `applyComponentPlan` in `apps/plugin/src/write-components.ts`, with its one-line classifier: "does the node I am writing to still exist, whole, after this fails?"

- **Code that moved.** Three property sites propagated and now record: the `setBoundVariable` field loop (one refused binding used to end a 648-member build), `setTextStyleIdAsync`, and `setEffectStyleIdAsync`. A refused binding is not pushed to `wrote`, so the read-back does not also report a write that never landed; a refused text style leaves `appliedStyle` unset, so the #1567 re-apply does not retry it. `EXECUTOR_REVISION` 32 → 33. Structure calls (`createFrame`/`createText`/`appendChild`, `createComponentFromNode`, `combineAsVariants`) are untouched and still reach the #913 guard.
- **Two older pins moved with it, deliberately.** The #680 pin ("a brand whose typeface is not installed loses the WHOLE component build") was written as the assertion that would invert once the style apply was guarded; it now asserts the build finishes and reports both the font load and the style apply. #913's small regime used that same missing-typeface throw to reach a mid-build failure, so it now drives a refused `createText` instead (a structure call, the class that still stops). Its assertions read the host and are unchanged.
- **A third pin used the same throw.** `test-update-apply.ts` "stop" stopped a run with a refused `setBoundVariable`. It now throws from `unlockAspectRatio` (called on every node, unclassified by the rule), which keeps its meaning — a host stop part-way — without leaning on the property class.
- **Pinned by name.** `test-write-components.ts` `#982` arms drive a host that refuses one call: `setBoundVariable` and `setTextStyleIdAsync` must finish with a REFUSED miss; `createText` and `combineAsVariants` must throw. The shim gained `refuse.createText`, `refuse.setBoundVariable` (by field), `refuse.setTextStyleId` and `refuse.setEffectStyleId`.
- **Not decided here.** `resize`, `setBoundVariableForPaint` and the paint-array assignments were not reclassified: `resize` clears every dimension binding (a known blast radius) and the paint sites need their own host model. Neither is a structure call, so under the rule they are properties; moving them is a follow-up with its own measurement, not part of this concern.

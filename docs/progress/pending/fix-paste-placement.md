## (2026-11-20) — The MCP paste places sets and standalone components as the plugin does (#2610, #3139)

Two placements the plugin fixed never reached the paste paths.

**#2610, a set under the section header.** The chunk payload's copy of `placeNewSet` (`PAYLOAD_CHUNK_BODY`, `anatomy-figma.ts`) predated #2405 and #2598. On a page holding only its `_section-header`, it read the header as content, so the set took the header's `y` and went 160 right of it. The payload now finds the header by name, in any case, as an instance or a frame, the way `pageBox` does. The row's top is the sets' top, else the header's bottom + 80, and the set takes the first free slot scanning right from the header's left edge. Two `test.ts` arms at the end of the #1809 block pin literal coordinates worked by hand: a header alone (0,200, was 1360,0), and a header plus a kept set moved right (0,200, was 2164,200). Each has a parity arm with the plugin on the same page.

**The byte budget was the real constraint.** On `main` the indivisible unit (`#1798`) was 37,774 B against its 37,800 ceiling, 26 bytes of headroom, and the header rule costs about 240 in every chunk. Payload comments are stripped before measuring, so moving comments buys nothing. The placement is dead code outside chunk 1, though, because a later chunk that finds no set returns NOT FOUND before the build. So `__prior` and `__place` now ship in chunk 1 only (`PAYLOAD_PLACE_FIRST`), later chunks ship two no-op stubs, and `planSetChunks` packs chunk 1 to its own measured shell. The worst unit is now 37,713 B (dialog), and icon-button still packs into 17 chunks.

**#3139, the standalone grid's pitch.** `runComponentEmit` (`apps/plugin/src/mcp-steps.ts`) laid each `emitAsComponents` member out on a fixed 48 pitch, so wide brand marks overlapped. The plugin measures its pitch on the page (#3134), but the paste slices a def across many scripts (83 for provider-logo), and each sees only its own slice. `emitPitch` (`mcp-paste.ts`) reads the pitch offline from the plans instead: each member's `glyphViewBox`, else its root's bound width and height resolved through the brand's tree (Spinner's `icon/size/*`), plus the plugin's 24 gap. It throws by name for a member with neither. `test-mcp-paste.ts` gains `emit/brand marks`, which drives `runComponentEmit` slice by slice with each script's own `__D`, on a page stub whose payloads build each mark at its own artboard size. On `main` it reports 12 overlapping pairs.

**Not changed: #1856.** A multi-chunk set is still placed at chunk 1's height. The options are an owner decision, posted on the issue.

## (2026-10-14) — Ecosystem diagram: a living, interactive map driven by one data file, checked against the code (#2637, Q300.4)

Lane 3 of #2637. `docs/public/ecosystem/` now holds `ecosystem.json` (29 nodes, 42 edges, 6 traces) and `index.html`, a single self-contained page that renders the diagram from that file: select a node for its purpose, inputs, outputs, members, sources and docs; trace one of six paths and watch each edge draw itself in order with a caption; filter by shipped, partial and planned; light and dark; a list view below 900 px; arrow keys move between nodes; reduced motion turns the trace into a static, numbered highlight. A new gate, `lint-ecosystem.ts`, runs in CI.

**What changed from the owner's static diagram.** Kept: the build-status legend (solid, dashed and hatched, dotted), the role colors, the two entry lanes, the engine as hub, the verification loop and the code-library layer. Corrected against the code: the plugin builds the whole component catalogue (the data lists every def, and CI holds it to `componentDefs`), with dry-run updates and previewed prunes; TokenPress is in this repo. Added: the agent link and its desktop bridge, the Figma MCP scripts, shipped skills, style guides, canvas furniture, Figma motion, the token contract and versioning, and CI gates.

**Two status calls worth re-checking when they move.** The desktop bridge is *partial*: the release build has no `devAllowedDomains`, so only a development build can open the socket (#2530). Motion in Figma is *partial*: FLOAT milliseconds on main, native TIMING and EASING in review (#2635); flip the node and its edge when that merges. The Style Dictionary build and CSS are *partial*: CI builds every platform, but nothing is published.

**The gate's independence.** The data is the subject and the code the oracle. MEMBERS imports `componentDefs`, `toolDefs`, `AGENT_COMMANDS` and the bridge's `TOOLS`, and reads skills from `git ls-files`, and compares each with the data's list in both directions, each with a floor. SOURCE asks git, not the filesystem, so an untracked local file does not pass. EDGE refuses an edge more built than either end: the first run caught one in the data itself (`dtcg>style-dictionary` was marked shipped into a partial node). CONTRAST takes its pairs from the gate and its values from the page's `:root` blocks, and fails if the two dark blocks (media query and toggle) drift apart.

**Mutations, each failing by name:** a def dropped from the data (MEMBERS), a command added to `AGENT_COMMANDS` (MEMBERS), an invented MCP tool (MEMBERS), a tracked skill added (MEMBERS), a moved source (SOURCE), a moved docs link (SOURCE), an edge to an unknown node (EDGE), a shipped edge into a planned node (EDGE), a trace step on a missing edge (TRACE), muted text at 2.43:1 (CONTRAST), the two dark blocks drifting (CONTRAST), the page fetching another file (PAGE), and the component import emptied (FLOOR).

**Trap for whoever moves a node.** Positions are hand-placed in canvas units. An edge can pass behind an unrelated node and still look connected to it; five edges carry `via` waypoints for that reason. The gate cannot see this. Open the page after any move.

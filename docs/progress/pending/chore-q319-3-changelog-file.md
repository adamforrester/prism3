## (2026-10-15) — The ENGINE changelog moves out of `version.ts` into `packages/engine/CHANGELOG.md` (Q319.3)

Owner decision Q319.3 on #2583, started once fold #2582 had merged. `version.ts` goes from 6,365 lines to 1,276. The 5,094 lines between its module header and `export const ENGINE_VERSION` move into `packages/engine/CHANGELOG.md`, in the same order, with only the comment syntax stripped (`/**`, ` */` and blank lines dropped, ` * ` and ` *` taken off each line). Below a `<!-- BODY` line, the file is the changelog and only a fold writes it. Above that line is a short preamble any PR may edit, as with `version.ts`'s module header. The `CONTRACT_VERSION` history stays beside its constant, because a PR still writes that bump itself (docs/30). Moving it would change a per-PR convention, which this decision did not cover.

- **`fold.ts`** writes the constant in `version.ts` and its section in `CHANGELOG.md`, directly below `── FOLDED CHANGE NOTES (#1807)`, now as plain lines rather than ` * ` comment lines. Its NOTE SHAPE refusal of `*/` went, because the prose no longer lands inside a comment. `lint-emission-version.ts` drops the same arm for the same reason.
- **`lint-emission-version.ts`** reads the changelog BODY at the base and at HEAD from git. The trap was the migration itself: the base has the changelog only as a comment, so a naive read would see the whole changelog edited by a non-fold PR. At a ref with no `CHANGELOG.md`, the gate strips the legacy comment with its own code, mirroring the move. So a base before the move and a HEAD after it compare equal exactly when nothing but the move happened, and this PR passes ONE WRITER as "no edit".
- **`lint-progress-order.ts`**'s pure-fold list (`FOLD_WRITES`) gains `CHANGELOG.md`. Without it, every future fold reads as impure and is asked for a fragment. That was measured on a replayed fold before the fix, not assumed.
- **Measured, not assumed:** a real `fold.ts` run in a scratch clone, over one replayed note plus the four fragments pending on `main`, wrote `0.238.0 — folded …` under the marker in `CHANGELOG.md` and moved the constant. `lint-emission-version.ts` passed it as a fold and `lint-progress-order.ts` as a pure fold.

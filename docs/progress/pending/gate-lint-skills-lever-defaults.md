## (2026-11-12) — lint-skills: each default a lever-table row states is the one the engine declares (#3385)

#3380 made `partial` the default for `currentIndicator`, and the theme skill's row still said "`full` (default)". Nothing failed: `lint-skills` read the row's lever name and its values, never which value it called the default. Check 10 closes that. For each skill that declares `documents: brandInput`, every table row whose first cell is a backticked setting and that states a default is compared with `default` on that lever in `levers.ts`. A row that is not a lever (`root`, an identity field, and `secondaryTextGround`, deliberately not a lever) is compared with its `default` in the hand-authored `theme-schema.json`. A row that states a default where neither declares one fails as `unheld default`.

**The marks it reads.** Three phrasings cover every default the theme skill states today: "`x` (default)" and a parenthetical that ends in the word ("`match` (Medium, default)", "`text` (Text & icon only, the default)"), "(default `x`)", and "default(s) to `x`", where an object default (`typography.underline`) must hold `x` in every field. The match is lowercase only, because "`default` (Default)" on `buttonLabelWeight` is that option's UI label, not a default mark. A statement in any other form is not read, so a floor holds the count of statements read from the real skill at 19, counted by hand. Rephrasing one mark ("`partial`, the default,") drops the count to 18 and fails the floor by name.

**No row was wrong.** All 19 statements agree with their source on `main`, so no skill text changes here. The `currentIndicator` row was fixed on #3380.

**Mutations, each failing the named assertion.** The skill row put back to "`full` (default)" fails `default drift` on `currentIndicator`. `levers.ts` changed to default `full` fails the same row from the other side. `theme-schema.json`'s `root` default changed fails `default drift` on `root`. Removing the call in `scanSkill` fails the wiring floor (ran 0×, read 0). Neutering the drift push fails the self-check's four drift samples. Raising the floor to 20 shows exactly 19 read.

**What it cannot see.** A default stated another way: "off by default" on the caption and size floors names no value, and `linkPalette`'s "Defaults to following the action color" names no backticked one. It also cannot see a default stated outside a table row, such as the prose under the table that says `action` defaults to `primary`.

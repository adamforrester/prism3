## (2026-11-15) — "Control label weight" reaches Tag through its own `levers` entry, not Tag style's (#3786)

**STATUS: PR open, not merged.** ENGINE {{ENGINE_VERSION}} (minor, `packages/engine/changes/claude-3786-tag-label-weight.md`: a new `levers` entry and its validator refusals), CONTRACT stands. The follow-up the owner asked for in Q-SD2: #3785 kept this coupling so that refactor stayed a pure move. **The entry's name, `buttonLabelWeight: { labels: true }`, is an OWNER DECISION** on the PR, one rename away.

**The coupling.** `applyButtonLayout` gives "Control label weight" to the button family by being the family (`isButtonFamily`). Outside it, Tag took the setting because it was in `TAG_STYLE_PARTS` (#2945, Q591 A), which became "`levers.tagStyle` is present" in #3785. So a def that wanted Tag style's underline got label weight too, and a def could not take label weight without the underline. Now `levers.buttonLabelWeight` is the opt-in, keyed by the `BrandInput` setting like every other entry. `applyButtonLayout` reads it, and `leverErrors` refuses `labels` other than `true`, and the entry on a def with no size axis (the setting rebinds each size's label type, and `withDefaultLabels` would rebind nothing). Tag carries both entries. The shape copies `outlineInteraction: { opaqueFill: true }`, the other entry that only opts a def in.

**Proof it is neutral.** `regen --check` is in sync. A plan diff over every def × Tag style (2) × Control label weight (2), on six brand inputs and both materializer chains, hashing each materialized def and its full anatomy set: 0 differences. The same harness with Tag's new entry dropped reports Tag's plans moving under Default, so it does see the setting.

**The tests.** The #2945 tag lines and the #1752 scope line already fail when label weight stops reaching Tag. Two new lines hold the decoupling from both sides against the label refs spelled out in the test: with `levers.tagStyle` dropped, Default still reaches Tag; with `levers.buttonLabelWeight` dropped and `levers.tagStyle` kept, Default leaves Tag as authored. The R5 reach table and the validator cases name the new entry.

## (2026-10-24) — Badge: a size axis and a third emphasis, surface, for the status label (#2983, draft)

Owner decision Q644 A makes the commerce-card label on a product image a `badge` type=status. The first draft added a separate `surface: default | media` axis. The owner turned that down on 2026-10-24. The white-container style is an `emphasis` level, its name must not say "media", and these labels are effectively small badges, so badge gets a `size` axis. This draft rebuilds to that direction on the recommended answers to Q2983.4–6 (wireframe v2, a private Artifact linked on #2983) and waits for the owner.

- **`size: small | medium`,** authoring. `medium` is today's label and leads the axis, so every existing member keeps its place. Small (Q2983.5 rec A) is `type.caption.md.strong`, the corpus's only 11px rung, at `space.025` × `space.100`, about 19px tall. The count and dot stay medium.
- **`emphasis: subtle | bold | surface`** (name pending Q2983.4). Surface is `background.primary` under `text.<tone>` (neutral: `text.primary`) with no edge. It shares the subtle and bold box, so `emphasis` stays runtime. Lowest text-on-fill across the corpus is 4.94:1. On a card the fill barely separates (1.22:1 at most), so there it reads as tone-colored text.
- **Neutral + bold is not near-black in every mode.** It is the inverse surface: near-black on light and hc-light pages, near-white on dark and hc-dark, with text at 12.33:1 or more. Raised as Q2983.6 rather than adding a tone. `test.ts` holds today's behavior per mode with literal luminance bands.
- **Figma:** 20 → 40 members. The paint grammar is unchanged (`{tone}.{type}.{emphasis}.{slot}`); the padding and type keys gain the size (`{type}.{size}.pad-*`, `{size}.type`).
- **Trap:** nb-redesign ships its bold caption under a different role, so a hard `caption.md.strong` failed #1601 by name. `typeWeight: { group: 'caption', intent: 'bold' }` repoints it per brand, as Code input does for titles.
- **Trap:** the #910 presence sweep holds each def at its SECOND size, which for badge is `small`, where the count and dot do not exist. The sweep now reads a size-sparse coordinate at a size the set has.

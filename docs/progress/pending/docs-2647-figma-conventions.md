## (2026-10-15) — Docs: a generated Figma conventions file for agents and tools (#2647, Q306.2 A)

Owner Q306.2 A, part of #2637. `packages/engine/emit-figma-conventions.ts` writes `docs/public/reference/figma-conventions.json`, served beside the agent reference and linked from `llms.txt`. It says how a Prism3 Figma file is laid out and named, so a spec tool, the rebind skill, TokenPress or an agent can read one without reading the engine.

**What it holds, and where each part is read from.**
- **Pages:** `TAXONOMY` and `NEST_PREFIX` (`file-taxonomy.ts`): the cover, each section's header and order (alphabetical or as listed), and every `↳ ` page with the defs it holds.
- **Components:** the projector itself. `figmaAnatomySet` and `planSetProperties` run over every def, so each set's name (its def id), member count, variant properties (read back from `planComponentName`'s `key=value` names), other properties (with an instance swap's target) and page are what the plugin writes. Code-only axes and states are the def's `variants` and `states` that `figmaProperties` does not project; the schema already refuses any that `anatomy.codeOnly` does not admit. The `_` building-block prefix is flagged per def, with the rule cited from `component-schema.ts`.
- **Icons:** `iconComponentName` (the namespace is `iconComponentName('')`, so a renamed namespace moves every glyph entry), `ICON_INSET_CHILD`, and the glyphs the icon def's plans build.
- **Native slots:** every `SLOT` property `planSetProperties` declares, with its settings and preferred defs.
- **Variables:** `figmaArtifacts` over the canonical default theme, the same function `emit-figma.ts` writes `out/figma/**` with, so each collection and its modes are the ones the plugin creates. The fallback root is asked of `brandTheme` (the default input with its root removed) rather than read off the source text: a first cut matched `input.root ?? 'prism'` as text, and the same string sits in a header comment of `theme.ts`, so a mutation of the code line passed.
- **Canvas furniture:** `CANVAS_FURNITURE`, the `_Label`, `_inverse-backdrop` and `_scrim-backdrop` templates with their properties and bound variables, the `_Section-header` and `_Headings` file templates, and the shared plugin data tag a reader uses to skip furniture.

**Its own gate, the agent reference's posture.** `--check` regenerates in memory and compares with the committed file, reporting per page, section, component, glyph, slot, collection, style file, furniture membership and template. It also fails by name when a promised section comes out empty, so a source that stops yielding data cannot pass as a smaller file (docs/34: represented, not counted). Not a regen step, and no engine version, for the reason `emit-agent-reference.ts` gives. The new file reads `process.argv`, so it joins the agent reference's `CLI` list and `commands.json` is regenerated.

**Mutations (committed first, restored with `git reset --hard`), each failing by name:** `NEST_PREFIX` changed → `changed in the code: pages prefix` and every page; the Veil page renamed → `missing from the file: page ↳ Veils` / `gone from the code: page ↳ Veil`; the icon namespace changed in `iconComponentName` → `missing from the file: icon glyph/arrow-down` and on; `LABEL_SET` recased → `furniture template _label`; `FURNITURE_KEY` changed → `furniture tag`; `link` dropped from `CANVAS_FURNITURE` → `gone from the code: furniture on link`; the fallback root changed in `brandTheme` → `variables root default`; the `opacity` collection renamed in the emitter → `collection opacities` / `collection opacity`; slots filtered to nothing → `nativeSlots.slots is empty`. Renaming `CORE_TIER` breaks the Figma emitter itself before this gate reads anything.

**Trap, met in this PR.** A mutation's `git reset --hard` after a failed `--check` in the same `&&` chain wiped an uncommitted edit to the generator itself; the commit that should have come first was after the check in the chain. Commit, then mutate, as separate commands.

**Stated limits.** A def's code-only *props* are not listed: no schema field links a prop to the Figma property that carries it, and inferring one by name gave false hits. Each component entry links its component doc, where `anatomy.codeOnly` admits them in prose. Mode names are the default theme's; a brand that opts out of dark or high contrast emits fewer. The knowledge-base source the issue cites for the reference shape was not in the knowledge base at its current head; the file follows the issue's list.

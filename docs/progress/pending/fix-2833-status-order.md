## (2026-10-19) — One status order on every studio surface (#2833)

The studio listed the statuses three ways: the preview's Foreground, Text color, Icon and Border sections ran brand, danger, success, warning, info; the Foreground fills lever ran brand, success, warning, info, danger; the text, border and icon levers ran brand, success, warning, danger, info. The engine's `SEMANTICS` (`modes.ts`) is brand, success, warning, danger, info, and the emitted `text`, `icon`, `border` and inverse groups follow it, so that is the one order; no owner decision was needed. The preview's `SEM`, the Foreground fills lever's `SEM` and the preview's Icon and Border card lists now agree with it. The Icon and Border sections read `SEM` instead of restating the five names, so the preview has one source.

- **New gate, `apps/studio/test-status-order.ts`** (wired into the studio `test` script, so CI already runs it). The canonical order is a literal in the gate, checked against the committed emission's key order, then against the studio's row lists and `SEM` as built. Each row pattern (`foreground.*`, `foreground.*-subtle`, `text.on-*` and the rest) must be present and is named, so a dropped pattern fails rather than passing empty. Mutations: danger second in the preview's `SEM` fails `preview: SEM lists the statuses in the canonical order`; info before danger in the levers' `SEM` fails `levers: foreground.* rows list the statuses in the canonical order`.
- **One named exception, filed as #2836.** The emitted `color.foreground` group lists `danger` after the subtle tints. Reordering it moves every brand's emitted key order, so it is left alone and the gate records it as the exception; when it is fixed the exception's own assertion fails and says to delete it.
- Not touched: the Badge component's variant order (`info, success, warning, danger`) is the component's own API enum, and `STATUS_ROLES` (success, warning, danger, info) is already the canonical order without brand.
- The `test-smoke` and `test-chrome` literals that spelled the preview's old order now spell the canonical one.

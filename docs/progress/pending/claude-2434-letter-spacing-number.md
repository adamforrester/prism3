## (2026-11-11) — Letter spacing is a number multiplier, and container.fluid leaves the token layer (#2434)

Owner decision Q175 A (2026-11-11), taken together with #2423. The engine emitted two DTCG `dimension` tokens in units DTCG 2025.10 doesn't allow (it allows `px` and `rem`): the letter-spacing ladder in `em` and `container.fluid` as `100%`. #2424's platform gate measured the cost. Stock iOS, Android and Compose transforms read `-0.04em` as rem and wrote an absolute `-0.64`, right only at a 16px font size.

**What moved.** `core.font.letter-spacing.*` and `core.font.letter-spacing-role.*` (18 guaranteed paths) are `$type: number`, holding the bare multiplier (`-0.04em` → `-0.04`). `container.fluid` is removed, with no replacement path. `CONTRACT_VERSION` 14.15.0 → 15.0.0 (MAJOR: 18 retyped, 1 removed), accepted after the bump. No `DEPRECATIONS` entry, the 14.0.0 precedent: a retype keeps its name, and the removal has no path to point at. Values are unchanged: every step holds the same number it did. Figma text styles keep their baked PERCENT letter spacing (`lint-lineheight-bake`). The emitter reads the same multiplier from `$extensions.prism3.em`, so `out/figma/**` is byte-identical.

**How a platform applies it** is written once in `packages/tokens/README.md` ("Letter spacing") and in `prism3-build-ui`: `calc(var(…) * 1em)` in CSS, × point size as `kern`/`tracking` on iOS, as-is on Android (`letterSpacing` is already em), `.em` on Compose. The composites alias a role, so they carry the multiplier too. The stock CSS `font` shorthand has no letter-spacing field, so on web, set it beside the composite.

**The studio chrome was a consumer, and the chrome suite caught it.** `apps/studio/chrome/tokens.mjs` turns token values into `--p3-*` custom properties and passed letter spacing through as written, so after the retype it wrote a bare `-0.03`, an invalid `letter-spacing` that renders 0. `test:chrome` failed by name on every L1 and L2 heading (`… letter spacing 0, want ls-tighter …`). The resolver now has a multiplier kind (`M`) that writes `${value}em` and throws on a non-number, so the built CSS is byte-identical to before (`--p3-ls-tighter: -0.03em`). The studio Layout preview's "Full width" bar stays, with no token pill, since there is no token behind it any more.

**The platform gate's letter-spacing row** now pins the multiplier on all six platforms: `-0.04` everywhere, plus `<integer>-0.04` on Android, tagged `[GAP #2433]` like the line height. The `#2434` gap tag is gone. Before the literals moved, the row failed by name in all 30 brand × platform cells (`… letter spacing -0.04em on ios — … = -0.04 (expected CGFloat(-0.64))`). `sd-version-matrix.md` is a tool's dated record (3718 base tokens then, 5 fewer now) and isn't regenerated here.

**New test arms** (`test.ts`, layout section): every emitted `dimension` in every committed token file is a px or rem literal or an alias (the unit set typed as a literal, from the spec); every brand's letter-spacing steps and roles are `number`, and each canonical brand is represented; `container.fluid` is absent from the DTCG and the Figma layout.

**Sequencing.** This PR carries the one contract bump for Q175. The Figma half (#2423: the line-height and letter-spacing primitives as Figma number variables) moves no DTCG name, so it lands after this with an engine change note only. Its collection name waits on the owner (asked on #2423).

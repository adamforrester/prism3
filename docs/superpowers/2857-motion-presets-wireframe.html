Motion patterns and their Figma animation styles

The starter set proposed by #2857 (Q-MO1 A), named per #3413 Q-M7 A: a data name such as dialog/enter, a Figma style such as “Dialog / enter”, and a “… / reduced” sibling. Every entry binds a published role variable (duration/*, duration-reduced/*, easing-role/*), never a hidden primitive.

How to read this. Each card plays its pattern on the example brand's emitted values (prism3, standard tempo, from out/figma/prism3/motion.json at d9078034). Tags such as OD-1 mark an owner decision; each one is listed with options and a recommendation at the end. Copy, names and scale values on this page are DRAFT placeholders.

The reduced-ramp menu previews the #3484 / #3493 choice in the G1–G6 batch; it changes only what the reduced siblings resolve to. The checkbox starts on when your system asks for reduced motion.

What the picker shows, and what it doesn't

  • A style and its reduced sibling sit together: “Dialog / enter” is a style, and “Dialog / enter / reduced” makes “enter” a folder beside it. Unverified in the app: whether Figma shows a style and a folder of the same name side by side, or merges them. Checking it is the first in-app task. OD-5
  • Each style's entries bind role variables, so a brand's tempo change re-times every style without a re-apply. The #2857 checks verified this for a duration role and an easing role, in the owning file and, after publish and accept, in a consuming file.
  • The picker groups by component, not by motion kind (“Fade in · short · standard”, the issue's first example). OD-4
  • No “Motion /” prefix: animation styles already have their own section in Figma. OD-4

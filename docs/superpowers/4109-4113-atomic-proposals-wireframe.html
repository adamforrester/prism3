Skeleton, Avatar, Toggle button and Image: wireframe

For the four atomic proposals from #4001 (Q-AT2): Skeleton #4109, Avatar #4110, Toggle button #4112, Image #4113. Gray boxes to show parts, axes and members, not a visual design. Where a proposal names a token, the box uses the example brand's emitted value for it, in light and dark. Each OD-xx tag points at an owner decision in that proposal. The page draws the recommended option for each one, and nothing here is decided.

1 · Skeleton #4109

One primitive with a shape axis, composed by the consumer inside the real layout (OD-S2). No page-sized skeleton. Aliases: placeholder, loading-placeholder, shimmer, skeleton-text, skeleton-avatar, skeleton-image; ghost left off, so it still reaches nothing (OD-S1).

Parts

container › line1–3 (24px row, type.body.md.line-box) › bar1–3 (paint fill)
block

Only the bars and the block carry paint. The container and the line rows are geometry. The bar is two thirds of its line box, centered, so stacked lines keep the text's rhythm (OD-S5): 16px in a 24px row at medium, 14px in a 21px row at small. Widths 100 / 80 / 40%. Bar radius radius.sm (2px).

Live: animation and reduced motion (OD-S3)

One cycle is motion.duration.sweep (1600ms), so no token is minted. Pulse fades the whole shape; shimmer moves a highlight (color.background.secondary) with transform, in the reading direction, so it reverses under RTL. Turn on reduced motion: the animation stops and the still shape stays, with no substitute. Figma draws the still frame only.

2 · Image, with its Skeleton loading state #4113

Image placeholder is renamed to Image through the rename register, so the Figma set and its instances update in place (OD-I1). Its ratio lock, clipping, nominal width (container.narrow) and marker carry over unchanged as the empty state. The loading state nests Skeleton at shape=rect, filling the frame (OD-I4), so it pulses, shimmers or stops exactly as section 1 does.

Live: loading → loaded, or loading → error

status=empty · no src

The photo is a stand-in gradient. It fades in over the skeleton on motion.duration.fast (100ms) with motion.easing-role.enter; under reduced motion the fade stays (it is not vestibular) and the skeleton's pulse stops. On error the informative image keeps its name (role="img", aria-label = its alt) and draws no alt text as visible text.

4 · Toggle button #4112

A new def built on Button through the same factory pattern as makeButton: Button's anatomy, sizes, spacing, focus ring, density and controlShape, plus a selection axis. Button's own sets do not change (OD-T1). Two defs, ToggleButton and ToggleIconButton, so the icon-only one requires its accessible name at the type level (OD-T4).

Live: pressed state by keyboard

Text format
Tab to a button, then press Space or Enter.

A native <button> with aria-pressed. Space and Enter both toggle; each button is its own tab stop. The label never changes ("Pin", not "Unpin"). Hold the key or pointer to see the transient press (Button's overlay step and 0.98 scale) next to the persistent selected look. The format row sits in a labeled role="group" in code; no group def now (OD-T5).

Appearances: outline and text, no filled, so selected stays the strongest look (OD-T3). On a brand whose outline interaction is none, the tint is not emitted and the outline carries selected alone.

Drawn at medium only (40px is a stand-in for Button's medium height). selection leads with unselected, the code default and the Figma default member. Selected and unselected share one footprint. inactive stays code only, as Button has it. One text, label ("Toggle"); the leading slot is Button's, with its swap.

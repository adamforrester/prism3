- `2353-icon.png`: icon size, drawn as a dimension table ("Icon").
- `2353-opacity.png`: the new Opacity table, each value with its swatch.
- `2353-text-styles.png`: the changed Text styles table, first 12 of 74 rows, with the new Style column. Weight now reads "500 · Medium" where it read "500 · Medium Italic".

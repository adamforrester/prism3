Changes from v1 sketch

  • Accent shifted to Figma blue (#0D99FF) — buttons, toggles-on, focus rings, active step.
  • Removed: Live JSON preview pane, "Copy to clipboard" button, top-right Settings cog (no global settings yet), "Compile composite tokens" toggle (always on, not user-configurable), "Resolve aliases to raw values" toggle (not yet a feature).
  • Added: Namespace / prefix text input (was missing in v1), additional-format chips for CSS / raw / dot-notation (these are additive, not mutually exclusive).
  • Validation moved from inline strip in the main panel to a smaller chip in the left rail — out of the way, still discoverable.
  • Mode counts dropped from collection meta to keep cards tidier.

Maps to current options 1:1

  • Color format / color space / units / line height output / letter spacing units / dimension format / letter spacing format → setting cards
  • Namespace → text input
  • Include $extensions.figma, Emit DTCG keys → toggles
  • CSS / raw / dot-notation → format chips (DTCG always on)
  • SD / DTCG presets → Quick presets row (current button pair, just visually refreshed)

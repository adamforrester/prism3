Design rationale

  • Unified flow. No more Scan / Export tab split — scan happens once on open, status lives permanently in the left rail, configure + export are now the same surface.
  • Step tracker in the topbar gives users orientation: Scan → Validate → Configure → Export.
  • Left rail is the "what" (which collections), main panel is the "how" (format options + behavior).
  • Toggles instead of checkboxes for behavior options — clearer on/off state, more modern, paired with explanatory hints.
  • Setting cards group related dropdowns with hint text instead of tiny labels — easier to skim at a glance.
  • Inline live preview of the JSON output that updates as settings change — addresses "what does this option actually do?"
  • Validation strip surfaces warnings without forcing a separate tab.
  • Footer reserved for the export action — the primary CTA is always visible. Token count + file size act as a "ready to ship" gauge.
  • Color palette shifts from utilitarian Figma-default greys to a slightly warmer dark theme with a violet accent (still Figma-friendly via --figma-color-* when implemented). Keeps respectful of Figma's design language without copying it.

What's NOT changing

  • All underlying functionality — same options, same outputs, same converter logic.
  • ES2018-only constraint still applies when implemented.
  • Per-mode CSS export, HSL/sRGB option, dimension format toggle — all preserved.

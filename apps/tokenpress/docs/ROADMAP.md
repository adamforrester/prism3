**Status:** Not implemented, documented for future

**Priority:** Medium

**Scope:**
- Token conversion edge cases (circular refs, missing values)
- File structure edge cases (empty collections, deep nesting)
- DTCG compliance validation
- Performance regression tests

**Estimated Effort:** 2-3 hours

**Value:**
- ✅ Catch regressions when refactoring
- ✅ Document expected behavior
- ⚠️ Plugin manually tested and working
- ⚠️ Edge cases relatively rare


## Additional Export Formats

### Current State

**Infrastructure Ready:**
- `CSSFormatExporter` exists but not exposed in UI
- `MultiFormatTokenExporter` can use multiple exporters
- `exporterRegistry` system in place
- `BaseFormatExporter` provides common functionality

**To Enable Additional Formats:**
1. Create format exporter extending `BaseFormatExporter`
2. Register in `MultiFormatTokenExporter.initializeFormatExporters()`
3. Update UI to allow format selection
4. Pass format options from UI to exporter

---

### 1. CSS Custom Properties Export

**Status:** Code exists, not wired to UI

**Priority:** High

**Estimated Effort:** 1 hour (UI integration only)

**Current State:**
- `CSSFormatExporter` fully implemented
- Handles colors, dimensions, shadows, typography
- Supports CSS `var()` references for aliases

**Example Output:**

**Implementation Steps:**
1. Update `src/ui.html` to add CSS format checkbox
2. Use `MultiFormatTokenExporter` instead of `TokenExporter` in `src/code.ts`
3. Pass selected formats from UI to exporter
4. Test with sample tokens

### 2. SCSS Variables Export

**Status:** Not implemented

**Priority:** Medium

**Estimated Effort:** 1-2 hours

**Use Case:** Teams using Sass/SCSS in their projects

**Value:** Direct import into stylesheets without CSS custom property overhead

**Example Output:**
```scss
// Design Tokens - SCSS Variables
// Generated by Token Press

$color-primary: #007AFF;
$color-secondary: #5AC8FA;
$spacing-xs: 4px;
$spacing-sm: 8px;
$spacing-md: 16px;

// Typography mixins
@mixin typography-heading-1 {
  font-family: 'Inter';
  font-size: 32px;
  font-weight: 700;
  line-height: 1.2;
  letter-spacing: -0.5px;
}

@mixin typography-body {
  font-family: 'Inter';
  font-size: 16px;
  font-weight: 400;
  line-height: 1.5;
}

// Shadow mixins
@mixin shadow-elevation-1 {
  box-shadow: 0px 2px 4px rgba(0, 0, 0, 0.1);
}
```

**Implementation Plan:**

1. Create `src/plugin/format-exporters/scss-exporter.ts`:
```typescript
export class SCSSFormatExporter extends BaseFormatExporter {
  async export(tokens: DTCGFile, options: FormatOptions): Promise<PlatformExport[]> {
    const lines: string[] = [];
    lines.push('// Design Tokens - SCSS Variables');
    lines.push('// Generated by Token Press');
    lines.push('');

    // Export variables
    this.walkTokens(tokens, (token, path) => {
      const scssVar = '$' + this.sanitizeName(path, { caseStyle: 'kebab' });
      const value = this.transformToken(token, path);
      lines.push(`${scssVar}: ${value};`);
    });

    return [this.createExport('tokens.scss', lines.join('\n'), 'scss')];
  }

  getSupportedExtensions(): string[] {
    return ['scss'];
  }

  getDisplayName(): string {
    return 'SCSS Variables';
  }
}
```

2. Register in `MultiFormatTokenExporter`
3. Add unit tests
4. Update UI with SCSS checkbox option

### 3. Style Dictionary Format Export

**Status:** Not implemented

**Priority:** Medium

**Estimated Effort:** 1 hour

**Use Case:** Multi-platform transformation (iOS, Android, Web)

**Value:** Export to multiple platforms from single source using Style Dictionary

**Note:** Current DTCG JSON export already works with Style Dictionary. This would provide the Style Dictionary native format for teams who prefer it.

**Example Output:**
```json
{
  "color": {
    "primary": {
      "value": "#007AFF",
      "type": "color"
    },
    "secondary": {
      "value": "#5AC8FA",
      "type": "color"
    }
  },
  "spacing": {
    "xs": {
      "value": "4px",
      "type": "dimension"
    },
    "sm": {
      "value": "8px",
      "type": "dimension"
    }
  }
}
```

**Implementation:** Similar to SCSS exporter, but output JSON in Style Dictionary format instead of DTCG format.

## UI Enhancements

### Format Selection Interface

**Status:** Not implemented

**Priority:** High (required for multi-format export)

**Estimated Effort:** 2-3 hours

**Mockup:**
```
┌──────────────────────────────────────┐
│ Export Format                        │
├──────────────────────────────────────┤
│ ☑ DTCG (JSON)       [Primary]        │
│ ☐ CSS Custom Properties              │
│ ☐ SCSS Variables                     │
│ ☐ Style Dictionary                   │
└──────────────────────────────────────┘
```

**Implementation Steps:**

1. Update `src/ui.html`:
```html
<div class="format-selection">
  <h3>Export Formats</h3>
  <label>
    <input type="checkbox" id="format-dtcg" checked disabled />
    DTCG (JSON) - Primary format
  </label>
  <label>
    <input type="checkbox" id="format-css" />
    CSS Custom Properties
  </label>
  <label>
    <input type="checkbox" id="format-scss" />
    SCSS Variables
  </label>
  <label>
    <input type="checkbox" id="format-style-dictionary" />
    Style Dictionary
  </label>
</div>
```

2. Update export options handling in UI JavaScript
3. Pass selected formats to `MultiFormatTokenExporter`
4. Update ZIP structure to include folders for each format:
```
tokens.zip
├── tokens/
│   ├── primitives.json
│   └── typography.json
├── css/
│   └── tokens.css
└── scss/
    └── tokens.scss
```

**Additional Features:**
- Format-specific configuration options (e.g., CSS prefix, SCSS mixin style)
- Preview mode to show sample output before export
- Format validation warnings

1. **Additional Platform Exporters** (4-6 hours each)

   - iOS Swift
   - Android XML/Compose

2. **Advanced Export Options** (2-3 hours)
   - Custom naming conventions
   - Token filtering by type/collection

   - Accessibility contrast checking
   - Token naming convention enforcement
   - Duplicate value detection

4. **Performance Improvements** (2-4 hours)
   - Incremental exports (only changed tokens)
   - Worker thread support for large token sets
   - Streaming ZIP generation

5. **Developer Experience** (3-5 hours)
   - Export templates/presets
   - Import from other token formats
   - Token diff/comparison tool
